# Expected data paths

National CSV files:

```text
public/data/top/{year}data.csv
```

Municipal CSV files:

```text
public/data/{region-folder}/{year}data.csv
```

The region-folder mapping is defined in `src/Dashboard/config.js`.

Optional insight files:

```text
public/data/analysis_insights.json
public/data/analysis_insights.csv
public/data/insights.json
public/data/insights.csv
```
